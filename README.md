# 煮飯仔 · 七個灶頭料理模擬

單頁網頁遊戲（`index.html`），唔使安裝，直接用瀏覽器開。玩法參考《九轉丹房》：揀好設定，按次序落料，睇下煮成點。

## 場景
| 場景 | 特色 |
|---|---|
| 普通屋企 | 雪櫃剩菜免費；爐頭最大火 7；炸嘢會油彈 |
| 學生宿舍 | 得電磁爐同電飯煲；火候 6 有機會跳掣；炸嘢、燒嘢會引舍監沒收 |
| 大排檔 | 火候去到 9；鑊 + 炒 + 火候 8 以上有鑊氣；猛火有機會起火 |
| 茶記冰室 | 出餐快有加分，太慢客人會嬲 |
| 扒房 | 每餐客人有指定熟度（一成至全熟） |
| 法國餐廳 | 食材貴、賣得貴；冇主廚幫手會扣分 |
| 野外求生 | 食材靠捉同採集，唔一定成功；營火忽大忽細，會落雨；野菇有機會有毒 |

每個場景有自己嘅**食材來源**（街市、超市、凍肉舖、海鮮檔、法國空運、溪邊、陷阱……，價錢同品質唔同）、**幫手**、**廚具**同**食譜**。

## 玩法
1. **灶台**：揀食譜（或者自由發揮）、幫手、煮法（炒／煎／炸／煮／炆／蒸／焗／燒／涼拌）、廚具、火候同時間。撳「跟食譜設定」會自動揀好。
2. **食材**：撳一下落鑊，次序就係落鑊次序，可以上下移。越早落嘅嘢煮得越耐。
3. **鑊**：每樣食材即時顯示預計熟度（生／半生／啱啱好／過火／燶，扒就係一成至全熟），下面有鹹甜酸辣鮮香油分佈同預計分數。
4. **開煮**：睇住時間線，出結果：評級 S 神級料理、A 好味、B 家常水準、C 求其啦、D 難食、E 黑暗料理。
5. **處理**：自己食（補身或者肚痛）、出餐收錢／俾屋企人食／同隊友分享、影相打卡賺名聲、或者倒咗佢。

評分睇六樣：熟度、次序、調味、配搭、廚具、食材品質，再加減鑊氣、爆香、幫手、場景事件。

錢唔夠就**去打工**（耗一日）。廚藝等級越高，熟度容錯越大。食生嘢或者毒菇會病，健康歸零要入院。

**食譜圖鑑**記錄晒煮過嘅食譜同自創料理。進度儲喺瀏覽器 localStorage（`cookrice.v1`）。
