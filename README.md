# 煮飯仔 · 七個灶頭料理模擬

單頁網頁遊戲（`index.html`），唔使安裝，直接用瀏覽器開。玩法參考《九轉丹房》：揀好設定，按次序落料，睇下煮成點。

開發者請睇 [`CLAUDE.md`](CLAUDE.md)，入面有程式結構、計分公式同改嘢指南。

## 場景
一開始只開到屋企同宿舍，其餘要**名聲**同**廚藝等級**夠先解鎖：

| 場景 | 解鎖條件 | 特色 |
|---|---|---|
| 普通屋企 | 一開始已開 | 雪櫃剩菜免費；爐頭最大火 7；炸嘢會油彈；出餐唔收錢，賺名聲 |
| 學生宿舍 | 一開始已開 | 得電磁爐同電飯煲；火候 6 有機會跳掣；炸嘢或者燒嘢會俾舍監沒收 |
| 茶記冰室 | 名聲 10 · Lv2 | 出餐快有加分，太慢客人會嬲 |
| 大排檔 | 名聲 25 · Lv3 | 火候去到 9；用鑊炒、火候 8 以上有鑊氣；猛火有機會起火 |
| 野外求生 | 名聲 20 · Lv3 | 食材靠捉同採集，唔一定成功；營火忽大忽細；會落雨；野菇有機會有毒 |
| 扒房 | 名聲 50 · Lv4 | 每餐客人指定熟度，由一成到全熟 |
| 法國餐廳 | 名聲 80 · Lv5 | 食材貴、賣得貴；冇主廚幫手會扣分 |

每個場景都有自己嘅背景畫面、**食材來源**、**幫手**、**廚具**同**食譜**，總共 35 個食譜。食材來源例如街市、超市、凍肉舖、海鮮檔、法國空運、溪邊、陷阱，價錢同品質都唔同。

## 玩法
1. **灶台**（左邊）：揀食譜（或者自由發揮）同幫手。兩樣都可以摺埋。
   - 揀咗食譜之後，撳「跟食譜設定」會自動揀好廚具、煮法、火候同時間。
   - 俾錢可以叫幫手出**神助攻**。
2. **鑊**（中間）：上面係廚具動畫。
   - 動畫四個角：左上揀廚具（加「升級」掣）、右上揀煮法、左下火候、右下時間。
   - 下面嘅落鑊格一行 5 個，可以拖動調次序。越早落嘅嘢煮得越耐。
   - 每格即時顯示預計熟度。下面仲有鹹甜酸辣鮮香油分佈，同埋預計分數。
3. **食材**（右邊）：撳一下就落鑊。
4. **開煮**：睇住動畫同時間線，食材會一樣樣跌入鑊。之後出結果：
   S 神級料理、A 好味、B 家常水準、C 求其啦、D 難食、E 黑暗料理。
5. **處理**：自己食（補身或者肚痛）、出餐收錢、影相打卡賺名聲，或者倒咗佢。
   - 屋企唔收錢，係俾屋企人食；野外係同隊友分享。

評分睇六樣：熟度、次序、調味、配搭、廚具、食材品質。之後再加減鑊氣、爆香、幫手、廚具等級同場景事件。

## 錢點用
- **買餸**。
- **升級廚具**：孖人牌 → Le Creuset → Mauviel 1830。熟度容錯會大啲、評分有加，最高級仲有火力上限 +1。
- **神助攻**：每次開煮收錢，幫手出絕招。例如阿媽調味一定啱、副廚扒熟度一定啱、侍酒師售價 ×2。
- 錢唔夠就**去打工**（耗一日）。人工會隨廚藝同名聲上升。

食生嘢或者毒菇會病。健康跌到 0 要入院。**食譜圖鑑**記錄晒煮過嘅食譜同自創料理。

進度儲喺瀏覽器嘅 localStorage（`cookrice.v1`）。
